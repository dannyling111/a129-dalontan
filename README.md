# 大龙潭 DALONTAN · park life

A129 独立仓库网页：把导览图里的山水铺成一座可走的低多边形公园生活模拟。步行上山、绕湖、串村；访客自己闲逛，园里还有游乐与侧景。

## 线上地址

- 首页：https://dannyling111.github.io/a129-dalontan/
- 仓库：https://github.com/dannyling111/a129-dalontan

纯静态 WebGL 页，打开即可。进度存在本机 `localStorage`。

## 怎么玩

- `WASD` 走路，拖拽环顾
- `E` 造访景点 · `M` 小地图 · `Esc` 暂停
- `1–4` 放置设施（长椅、灯、花坛、小食摊）
- 手机用左摇杆走、右滑看、点 E 互动

## 本地

```sh
npm install
npm run dev
```

构建：

```sh
npm run build
```

`dist/` 就是 GitHub Pages 发布目录。
